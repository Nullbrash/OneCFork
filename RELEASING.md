# Выпуск релиза OneCFork — порядок действий

Репозиторий: `Nullbrash/OneCFork`. Релизы публикуются от имени аккаунта
**Nullbrash** и только по явному решению владельца: релиз сразу виден всем,
а установленные программы сами скачивают его и ставят при закрытии.

## Версии

`Major.Minor.Patch`, при необходимости с суффиксом:

| Вид | Пример | Кому достаётся |
|---|---|---|
| Релиз | `1.2.0` | всем — автообновление |
| Бета | `1.2.0-beta.1` | никому автоматически: публикуется как **prerelease** |
| Проверка механизма обновлений | `1.2.0-updtest.1` | только prerelease; после проверки релиз и тег удалить |

Автообновление читает `releases/latest/download/latest.json`, а GitHub не
считает prerelease «последним» релизом, поэтому версия с суффиксом никому
не ставится сама. `publish-release.sh` помечает prerelease по суффиксу.

## Шаги

1. **Версия** — сразу в трёх файлах (тест следит, чтобы они совпадали):
   ```
   node scripts/set-version.mjs 1.2.0
   ```
   Закоммитить: `Bump version to 1.2.0`, запушить.
2. **Сборка с подписью** — запускает владелец ключа (пароль спрашивается
   скрыто и нигде не сохраняется):
   ```
   powershell -ExecutionPolicy Bypass -File scripts\build-release.ps1 "что нового"
   ```
   Скрипт прогоняет проверки (`npm run check`), собирает установщик и
   пишет `latest.json`. Результат — в `src-tauri\target\release\bundle\nsis\`:
   - `OneCFork_<версия>_x64-setup.exe` — установщик;
   - `OneCFork_<версия>_x64-setup.exe.sig` — подпись;
   - `latest.json` — описание версии для автообновления.
3. **Публикация** (из Git Bash):
   ```
   bash scripts/publish-release.sh "что нового"
   ```
   Скрипт сверяет аккаунт разрешения GitHub **по API** (а не по имени,
   которое показывает Git Credential Manager), проверяет права на запись,
   создаёт релиз `v<версия>` и загружает три файла **строго под этими
   именами** — на них ссылается `latest.json`.

## Ключ подписи

- Секретный ключ — `%USERPROFILE%\.tauri\onecfork.key`, только на ПК
  владельца, с паролем; в репозиторий не попадает никогда. Публичный ключ —
  в `src-tauri/tauri.conf.json` (`plugins.updater.pubkey`).
- Программа ставит только обновление с верной подписью этим ключом.
  **Потерян ключ — установленные копии больше не обновятся сами**: нужен
  новый ключ и одна ручная установка новой версии.

## Что важно помнить

- Установленная (релизная) программа работает с **рабочей** базой
  (`onecfork.db`); отладочная сборка — с тестовой. Это разные файлы.
- Установщик ставит программу только для текущего пользователя, без прав
  администратора.
- Скачивание обновления — в фоне, установка — при закрытии программы или
  по кнопке «Перезапустить сейчас»; перед установкой делается резервная
  копия (если включена и были изменения).
